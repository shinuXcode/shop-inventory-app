# Shop Inventory App

Offline-first Android shop management app built with Flutter.

## Features
- Dashboard with live local metrics
- Product catalog with search, filters, stock tracking
- Product stock adjustments and transaction ledger
- Billing / POS with cart and totals
- Customer management
- Supplier and purchase tracking
- Expenses and reports
- Local backup and restore
- Android-ready offline-first design

## Getting started

```bash
flutter pub get
flutter test
flutter run
```

## Build

```bash
flutter build apk --debug
flutter build apk --release
```
